# Daily Quotes — generated example app

This app was generated by the multi-agent pipeline in this repo as an end-to-end
demonstration. It fetches quotes from `api.quotable.io` (Retrofit), caches them
offline and tracks favorites (Room, offline-first), and shows them in a Compose
Material 3 UI with MVVM + Hilt.

## Who generated what

| Layer | Produced by |
|-------|-------------|
| Contracts (`Quote`, `NetworkResult`, `QuoteRepository`) | `android-architect` |
| Gradle / manifest / version catalog | `android-build-engineer` |
| Room entity / DAO / db / mappers / `DataModule` | `android-data-engineer` |
| Retrofit API / DTO / `NetworkModule` / offline-first repo | network-engineer playbook |
| Compose screen / ViewModel / nav / theme | `android-ui-composer` |
| Unit + instrumented tests | `android-test-engineer` |
| Final review | `android-code-reviewer` |
| CI workflow | ci-engineer playbook (`.github/workflows/dailyquotes-ci.yml` at repo root) |

## Build & run

```bash
cd examples/DailyQuotes
./gradlew assembleDebug        # build the APK
./gradlew testDebugUnitTest    # run unit tests
```

Requires an Android SDK locally; otherwise let GitHub Actions build it (see the
`DailyQuotes CI` workflow). The Gradle wrapper is pinned to 8.7 (matches AGP 8.5.2).

See `docs/PROJECT_SPEC.md` (the shared spec all agents used) and
`docs/ARCHITECTURE.md` (the layer diagram).
